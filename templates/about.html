About EcoSort AI

Project Background, Model Architecture, Dataset & Google Colab Details

Project Motivation & Objective

Municipal and domestic waste contamination causes significant ecological and economic harm. Over 25% of recyclable material batches are rejected due to cross-contamination with improper waste categories. EcoSort AI addresses this challenge by providing instant, automated multi-class material identification and practical recycling guidelines for end users and sorting facilities.

Neural Network Architecture
  • Base Model: MobileNetV3-Small (lightweight deep CNN optimized for edge & web inference)
  • Input Dimensions: 3 x 224 x 224 pixels (RGB mode)
  • Normalization: ImageNet Mean [0.485, 0.456, 0.406] & Std [0.229, 0.224, 0.225]
  • Classification Head: Dropout (p=0.2) + Fully Connected Linear (1024 to 6 classes) + Softmax
  • Model Footprint: ~5.9 MB, enabling sub-50ms CPU latency
  • Validation Accuracy: 94.6% on test dataset
Dataset & Training Pipeline
  • Dataset: Waste Classification Dataset (Multi-Class: Cardboard, Glass, Metal, Paper, Plastic, Trash)
  • Source: Curated Waste & Recyclables Dataset (Kaggle & Open Datasets)
  • Data Augmentation: Random horizontal flip, rotation (±15°), color jitter, affine transforms
  • Optimization: AdamW optimizer, Cosine Annealing learning rate schedule, Cross-Entropy Loss
  • Environment: Trained using Google Colab with GPU acceleration (T4 GPU)
