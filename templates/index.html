How the Classifier Works
1. Image Ingestion

Input image is validated, resized to 224x224 pixels, and normalized according to standard ImageNet statistics.

2. Neural Inference

The MobileNetV3 deep learning backbone extracts visual feature representations and generates class probability distributions.

3. Actionable Sorting

The web application displays the predicted class, top-k confidence metrics, and targeted recycling bin disposal tips.
